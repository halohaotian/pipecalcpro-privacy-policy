# PipeFlow Tool Pro — Privacy Policy

This repository hosts the privacy policy for **PipeFlow Tool Pro** (Bundle ID: `com.tenx.pipecalcpro`), an iOS application available on the App Store.

## About PipeFlow Tool Pro

PipeFlow Tool Pro is a professional pipe flow calculation and plumbing utility tool designed for engineers, plumbers, and contractors. The app works entirely offline and does not collect any user data.

## Key Privacy Points

- **No data collection** — The app does not collect, store, transmit, or share any personal data.
- **No internet required** — All features work completely offline. No network requests are made.
- **No third-party services** — No analytics, no ads, no crash reporting, no social SDKs.
- **No tracking** — No cookies, no device identifiers, no usage tracking of any kind.
- **Data stored on device only** — Calculation inputs are held in temporary memory and discarded when the app is closed.
- **Children's privacy** — The app does not knowingly collect data from anyone, including children under 13.
